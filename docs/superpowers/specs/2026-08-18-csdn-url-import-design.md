# CSDN 文章 URL 导入设计

## 目标

在博客管理端提供单篇 CSDN 公开文章导入能力。管理员输入 `blog.csdn.net` 文章 URL、选择本地分类后，系统抓取文章、转换为 Markdown、尽力将正文图片迁移到本地，并创建一篇草稿。导入完成后进入现有文章编辑页，由管理员检查、补充标签并手动发布。

第一版不支持任意网站、批量搬家、登录态文章、付费文章、评论或阅读数据导入。

## 用户流程

1. 管理员在新建文章页面点击“URL 导入”。
2. 输入公开 CSDN 文章 URL，并选择一个已有分类。
3. 前端调用受登录保护的导入接口，并展示处理中状态。
4. 后端校验 URL、抓取页面、提取内容、转换 Markdown、迁移图片。
5. 后端以 `draft` 状态创建文章，记录规范化后的来源 URL 和来源平台。
6. 前端显示解析警告并跳转到新草稿编辑页。
7. 管理员检查正文、分类、标签和封面，最后使用现有发布流程发布。

导入绝不自动发布。

## 架构

### 管理端

在 `blog-admin/src/views/article/Edit.vue` 增加轻量导入弹窗，复用已经加载的分类数据。新增 API 方法调用 `POST /api/v1/admin/article-imports`，请求包含：

```json
{
  "url": "https://blog.csdn.net/example/article/details/123456",
  "category_id": 1
}
```

响应包含创建的文章 ID 和非致命警告。页面收到成功响应后跳转到 `/articles/edit/:id`。

### 后端接口

新增独立的 `article_import` API 模块和 `ArticleImportService`，避免把网络抓取、HTML 解析和文件落盘混入现有文章 CRUD 控制器。

服务划分为：

- URL 安全校验与 HTTP 获取：只接受 HTTPS/HTTP 的 `blog.csdn.net` 公开文章 URL；限制重定向、超时、响应体大小，并阻止访问私网、回环、链路本地和非 IP 网络地址。
- CSDN 解析器：从稳定语义字段和 DOM 候选选择器中提取标题、正文、摘要、发布时间和首图。正文主选择器为 `#content_views`，元数据优先读取 Open Graph/文章元标签。
- HTML 到 Markdown 转换器：保留标题、段落、强调、引用、列表、代码块、表格、链接和图片；删除脚本、样式、按钮等页面噪声及危险 HTML。
- 图片本地化器：仅处理公开 HTTP(S) 图片，限制数量、单图大小和总大小，校验真实 Content-Type，保存到 `uploads/article`，并将 Markdown URL 替换成本地路径。单图失败时保留原 URL 并返回警告，不让整篇文章失败。
- 草稿创建：调用现有文章服务创建草稿；创建失败时删除本次已下载的图片。

### 数据模型

文章增加以下可空字段：

- `source_url`：规范化后的来源 URL，唯一索引用于阻止重复导入。
- `source_platform`：第一版固定为 `csdn`。
- `source_published_at`：能解析时记录原始发布时间。

普通手工文章的 `source_url` 保持 `NULL`，避免唯一索引与空字符串冲突。后台详情响应带回这些字段，编辑文章时不允许普通表单覆盖来源信息。

## 数据和错误处理

规范化 URL 时移除 fragment 和非必要查询参数，保留 scheme、host 和 path。相同规范化 URL 已存在时返回明确的重复导入错误以及已有文章 ID，不再下载图片或创建新草稿。

致命错误包括：

- URL 不是允许的 CSDN 文章地址；
- 目标解析为非公网地址；
- 页面请求超时、状态码异常或响应过大；
- 找不到标题或正文；
- 转换后的正文为空或超过允许上限；
- 分类无效或草稿创建失败。

非致命错误包括个别图片下载失败、发布时间无法识别、没有摘要或封面。它们通过 `warnings` 返回，并保留可编辑的草稿。

## 安全边界

- 导入接口必须经过现有 JWT 管理员认证。
- 文章页面只允许 `blog.csdn.net`；图片只允许公开 HTTP(S) 地址，并同样执行私网 IP 拦截。
- 自定义 HTTP 客户端设置连接、TLS、响应头和整体超时；最多跟随有限次重定向，每次重定向重新校验。
- 页面、单图、图片数量和图片总量均设置上限。
- 不携带用户 Cookie、CSDN 登录凭证或浏览器会话。
- HTML 转 Markdown 时不保留脚本、iframe、事件属性或 `javascript:` URL。
- 前台仍执行现有渲染净化；导入器生成的 Markdown 不依赖原始 HTML 执行。

## 兼容性策略

CSDN DOM 会变化，因此解析器使用按优先级排列的选择器，而不是把选择器散落在控制器中。解析测试使用最小化的 CSDN 页面 fixture，覆盖主结构、备用结构、代码块、表格和图片。将来页面改变时只调整解析器及 fixture。

第一版不尝试绕过验证码或反爬限制。若 CSDN 返回验证页面，接口明确提示“目标页面暂时无法读取”，管理员可以稍后重试或从 CSDN 编辑器导出 Markdown 后手工导入。

## 测试

### 后端

- URL 规范化、域名白名单和私网 IP 判定单元测试。
- CSDN HTML fixture 到结构化文章/Markdown 的解析测试。
- 危险标签和协议被移除的测试。
- 图片类型、大小限制、失败降级和成功替换测试。
- 重复来源 URL 不创建文章测试。
- 导入成功只创建草稿并保存来源字段测试。
- 路由需要认证以及请求参数校验测试。

### 前端

- 构建验证。
- 手工检查导入弹窗的 URL、分类必填、加载态、错误提示、警告展示和成功跳转。
- 在窄屏下确认弹窗不会溢出。

## 验收标准

- 一个公开 CSDN 单篇文章 URL 可以导入为本地草稿。
- 标题、正文结构和代码块可在现有 Markdown 编辑器中正常查看。
- 可下载的 CSDN 正文图片改为本地 `/uploads/article/...` URL。
- 同一来源 URL 不能重复导入。
- 导入过程中不会自动发布文章。
- 非 CSDN URL、内网目标、超大页面和危险内容被拒绝或净化。
- 后端测试与两个 Vue 应用的相关构建验证通过。

## 明确不做

- 通用网页正文抽取。
- 批量扫描 CSDN 用户主页。
- 使用账号 Cookie 获取非公开内容。
- 自动创建分类或标签。
- 导入评论、统计数据、专栏关系或 CSDN 特有互动组件。
- 为绕过反爬验证引入无头浏览器。
