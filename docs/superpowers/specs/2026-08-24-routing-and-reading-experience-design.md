# 正常路由与文章阅读增强设计

## 目标

前台使用不带 `#` 的正常 URL，后台稳定部署在 `/admin/`，并在文章页增加目录、代码块工具栏与图片加载状态。保留现有右下角圆形阅读进度，以及发布时间和最近更新时间展示。

## 路由与部署

- 前台路由使用站点根路径，文章地址保持 `/post/:slug`。
- 后台生产构建基准路径保持 `/admin/`，路由读取 Vite 的实际基准路径。
- Nginx 将 `/admin` 永久跳转到 `/admin/`，后台子路由回退到后台 `index.html`，其他页面回退到前台 `index.html`。
- API 与上传文件代理规则保持不变。

## 文章阅读增强

- 从 Markdown 二级、三级标题生成文章目录；标题获得稳定且去重的锚点。桌面端目录参考 Hugo Theme Stack，作为文章右侧的独立粘性栏展示；较窄屏幕隐藏侧栏，避免压缩正文。
- 代码块显示语言、复制按钮和 CSS 行号；继续使用项目已有的 Highlight.js 依赖。
- 正文图片默认懒加载和异步解码。加载失败时隐藏破损图片，原位置显示带图片说明的失败占位。
- 图片成功加载后仍可使用现有放大预览。
- 不新增文章更新记录模块，继续使用文章顶部已有的发布时间和更新时间。

## 交互与边界

- 目录使用原生锚点定位，并跟随滚动标记当前章节；正文、评论保持在中间主列。
- 复制失败时按钮显示失败状态，不阻断阅读。
- 本次不修改后台编辑器、文章数据结构或后端 API。

## 验证

- 文章渲染工具使用 Node 单元测试覆盖目录、代码块和图片属性。
- 前后台分别执行生产构建。
- 检查生成资源基准路径与 Nginx `/admin`、前台 history fallback 规则。
